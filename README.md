# 码匣 CodeCrate

开发者的日常工具箱，包含 145 个工具、12 个分类。

- 站点：https://codecrate.137101.xyz
- 功能：格式化、编解码、加密哈希、网络查询、颜色设计与 AI 辅助。
- 界面：中文默认、英文切换、主题切换、搜索、收藏、最近使用与手机导航。
- 开发：Node 24、pnpm 9.15.9，运行 `pnpm install --frozen-lockfile`、`pnpm run dev`。
- 构建：`pnpm run build`，输出 `dist`，通过 Cloudflare Pages Git 构建发布。
- 验证：`pnpm run typecheck`；站点与浏览器验收见 [部署文档](docs/CLOUDFLAREFREE.md)。
